# Godex Label Printer — анализ проекта и требования к MVP

**Документ обобщает результаты предпроектного анализа: цели, требования, выбор стека, ключевые технические решения и план работы.**

---

## 1. Идея проекта

Разработать desktop-приложение под Windows для печати этикеток (бирок) на принтерах Godex.

**Основной сценарий пользователя:**
1. Загружает Excel-файл с данными
2. Открывает (или создаёт) шаблон бирки
3. В визуальном редакторе размещает поля из Excel на шаблоне
4. Проверяет предпросмотр с реальными данными
5. Запускает пакетную печать всех выбранных строк

Программа должна быть максимально простой и понятной для оператора, с современным UX/UI.

---

## 2. Обзор аналогов и почему пишем своё

**GoLabel / GoLabel II** — бесплатная фирменная программа Godex. Умеет практически всё, что нужно, но:
- Проприетарная, исходников нет
- Нет полноценного API для встраивания в свои процессы
- Интерфейс перегруженный, не под конкретный сценарий склада

**gLabels** — open-source редактор этикеток под Linux, давно почти не развивается, не работает с EZPL.

**Godex EZPL Viewer** ([github.com/yibudak/godex-ezpl-viewer](https://github.com/yibudak/godex-ezpl-viewer)) — MIT-лицензия, офлайновый HTML-просмотрщик и мини-редактор EZPL с точным рендерингом. Полезен как справочный источник по нюансам рендеринга EZPL и как эталон для сверки превью, но не является заменой полноценной программы.

**Вывод:** готового open-source решения нет. Пишем своё.

---

## 3. Целевая аудитория и окружение

- **Пользователь:** один оператор на рабочем месте (мультипользовательский режим — не в MVP)
- **ОС:** Windows 10 / 11 (x64)
- **Работа:** офлайн
- **Принтеры:** модели Godex (поддерживающие EZPL), парк уточняется. В MVP закладываем 203 и 300 DPI.

## 4. Требования к MVP

### 4.1. Функциональные требования

#### F1. Работа с Excel
- F1.1. Загрузка файлов `.xlsx` без установленного Office
- F1.2. Выбор листа, если их несколько
- F1.3. Первая строка = заголовки (в MVP фиксировано)
- F1.4. Отображение таблицы данных в программе
- F1.5. Выбор строк для печати: все / галочками / диапазон «с N по M»
- F1.6. Опциональная поддержка колонки «количество копий»

#### F2. Редактор шаблона бирки
- F2.1. Задание размеров этикетки в мм (ширина, высота, зазор между этикетками)
- F2.2. Выбор DPI (203 / 300)
- F2.3. Холст с линейкой в мм и привязкой к сетке
- F2.4. Элементы: статический текст, поле из Excel, штрихкод, QR-код, линия, прямоугольник
- F2.5. Drag & drop, resize мышью, поворот 0/90/180/270°
- F2.6. Панель свойств выбранного элемента: координаты (мм), шрифт, размер, тип штрихкода
- F2.7. Привязка поля к колонке Excel через выпадающий список (заголовки Excel)
- F2.8. Отмена / повтор (Ctrl+Z / Ctrl+Y)
- F2.9. Удаление, копирование элементов

#### F3. Предпросмотр
- F3.1. WYSIWYG с подставленными данными выбранной строки Excel
- F3.2. Переключение строк «предыдущая / следующая» для проверки на разных данных
- F3.3. Показ границ этикетки

#### F4. Управление шаблонами
- F4.1. Сохранение шаблона в файл `.json`
- F4.2. Открытие сохранённого шаблона
- F4.3. Список последних открытых шаблонов на главном экране

#### F5. Печать
- F5.1. Выбор принтера из списка установленных в Windows
- F5.2. Печать одной тестовой бирки перед пакетом
- F5.3. Пакетная печать выбранных строк
- F5.4. Прогресс-бар с возможностью отмены
- F5.5. Базовые настройки: скорость (`^S`), темнота (`^H`), режим термо / термотрансфер (`^A`)

### 4.2. Нефункциональные требования

#### N1. Платформа
- Windows 10/11 x64
- Полностью офлайн
- Установщик `.msi` или `.exe`

#### N2. UX/UI
- Современный визуальный стиль (Fluent / WinUI-подобный)
- Русская локализация (английский — потом)
- Основной сценарий выполняется за 3–4 клика

#### N3. Производительность
- Excel до 10 000 строк открывается без зависаний
- Предпросмотр обновляется в реальном времени при редактировании

#### N4. Надёжность
- Автосохранение шаблона при редактировании во временный файл
- Валидация перед печатью: элементы не выходят за границы этикетки, обязательные поля привязаны к колонкам

#### N5. Совместимость с принтерами
- Отправка команд EZPL напрямую в принтер (через raw-порт Windows-драйвера или TCP:9100 для сетевых)

## 5. Что сознательно вынесено за пределы MVP

Следующее — задел на будущее, в первую версию не входит:

- Интеграция с Wildberries / Ozon (API продавца, импорт заказов FBS, печать готовых стикеров)
- Мультипользовательский режим и общие шаблоны на сервере
- Библиотека шаблонов с превью, экспорт / импорт
- Логирование заданий печати и крэш-репорты
- Тёмная тема и английская локализация
- Сервисные функции принтера (автокалибровка, тесты печати, самотест)
- Ручное указание строки заголовков в Excel, сложные фильтры данных
- Автоопределение и «умное» управление разными моделями Godex
- Печать через штатный Windows-драйвер как альтернативный способ (в MVP только EZPL)

## 6. Ключевые технические решения

### 6.1. Стек: C# / .NET 8 + WPF

**Обоснование выбора:**

- Нативный путь под Windows: печать, USB, реестр, установщики работают «из коробки»
- Зрелые библиотеки под все нужные задачи (см. ниже)
- Отличный визуальный редактор форм в Visual Studio, XAML-дизайнер с превью — критично для нашего редактора шаблонов
- Компиляция в один self-contained `.exe` (20–40 МБ), установщик собирается за полчаса
- WPF Canvas + Data Binding идеально подходят для редактора с drag&drop
- Огромное коммьюнити, любой вопрос уже разобран

**Рассмотренные и отклонённые альтернативы:**

- **Python + PySide6** — низкий порог входа, но проблемы с упаковкой (тяжёлый PyInstaller, конфликты с антивирусами), низкоуровневое `win32print`, вопросы лицензирования Qt
- **Electron / Tauri** — плохой контроль точных размеров при печати из браузерного движка, тяжёлые сборки
- **Avalonia UI** — кросс-платформенность здесь не нужна, а зрелость и количество примеров ниже WPF

### 6.2. Способ печати: прямая отправка EZPL

Команды формируются в текстовом виде согласно спецификации EZPL (см. `EZPL_EN_J_20180226.pdf`) и отправляются напрямую в принтер:

- **USB-принтер:** через WinAPI `OpenPrinter` / `WritePrinter` (raw mode) — есть готовый класс `RawPrinterHelper` от Microsoft
- **Сетевой принтер:** через `TcpClient` на порт 9100

**Преимущества:**
- Максимальная скорость печати
- Штрихкоды и QR генерирует сам принтер идеально (по командам `Bt` / `W`)
- Полный контроль над параметрами (скорость, темнота, сенсор и т.д.)

**Что нужно учесть:**
- Единицы принтера — точки (dots): при 203 DPI → 8 точек/мм, при 300 DPI → 12 точек/мм
- Все координаты внутри программы храним **в миллиметрах**, конвертируем в точки только при генерации EZPL
- Для превью на экране понадобится собственный рендерер (либо позднее — переиспользование логики из `godex-ezpl-viewer` под MIT-лицензией)

### 6.3. Формат шаблона: JSON

Простая схема:
```json
{
  "version": 1,
  "label": { "widthMm": 50, "heightMm": 30, "gapMm": 3, "dpi": 203 },
  "print": { "speed": 4, "darkness": 10, "mode": "T" },
  "elements": [
    {
      "type": "text",
      "id": "el-1",
      "xMm": 5, "yMm": 5,
      "rotation": 0,
      "font": "D", "fontSize": 12,
      "source": { "kind": "column", "columnName": "Артикул" }
    },
    {
      "type": "barcode",
      "id": "el-2",
      "xMm": 5, "yMm": 15,
      "barcodeType": "Code128",
      "widthMm": 40, "heightMm": 10,
      "readable": true,
      "source": { "kind": "column", "columnName": "Штрихкод" }
    }
  ]
}
```

### 6.4. Единицы измерения

Внутри всей программы — миллиметры. Пересчёт в точки принтера (`dots`) происходит только на этапе генерации EZPL-команд с учётом выбранного DPI шаблона.

## 8. Верхнеуровневая архитектура

```
┌──────────────────────────────────────────────────────┐
│                     WPF UI (View)                    │
│  MainWindow · TemplateEditor · DataView · PrintDialog│
└──────────────────────────────────────────────────────┘
                          │  (Data Binding, MVVM)
┌──────────────────────────────────────────────────────┐
│                    ViewModels                        │
│  MainViewModel · EditorViewModel · PrintViewModel    │
└──────────────────────────────────────────────────────┘
                          │
┌──────────────────────────────────────────────────────┐
│                     Core (модели)                    │
│  LabelTemplate · LabelElement · DataSource           │
└──────────────────────────────────────────────────────┘
      │                    │                    │
┌───────────┐      ┌──────────────┐      ┌─────────────┐
│  Excel    │      │   Renderer   │      │   Printing  │
│ (ClosedXML│      │  (Preview на │      │  (EZPL Gen  │
│  reader)  │      │   Canvas)    │      │  + RawPort) │
└───────────┘      └──────────────┘      └─────────────┘
```

**Модули:**
- **Core** — модели шаблона и элементов, независимые от UI
- **Excel** — чтение файлов, экспозиция колонок и строк
- **Renderer** — рисование превью на WPF Canvas (в мм → пиксели экрана)
- **EZPL** — генерация команд EZPL из шаблона и данных строки
- **Printing** — отправка сгенерированных команд в принтер (raw USB / TCP)
- **UI / ViewModels** — WPF-слой с MVVM

Модульность важна, чтобы позднее можно было заменить/добавить: другой источник данных (WB, Ozon, SQL), другой формат вывода (ZPL для Zebra), другой канал печати.

## 9. Ключевые EZPL-команды, используемые в MVP

Из спецификации EZPL Rev.J:

**Setup-команды (в начале задания):**
- `^Qx,y` — размер этикетки (высота, зазор)
- `^Wx` — ширина этикетки в мм
- `^Hx` — темнота (00–19)
- `^Sx` — скорость (2–7 in/s)
- `^AD` / `^AT` — режим термо / термотрансфер
- `^Gn` — режим сенсора (0 reflect / 1 see-through / 2 auto)
- `^L` — начало описания этикетки

**Элементы:**
- `At,x,y,x_mul,y_mul,gap,rotation,data` — текст (bitmap-шрифты A–H)
- `AT,x,y,w,h,g,s,d,m,data` — встроенный TrueType
- `Bt,x,y,narrow,wide,height,rotation,readable,data` — 1D-штрихкод (Code39, Code128, EAN, UPC и т.д.)
- `Wx,y,mode,type,ec,mask,mul,len,rotation<CR>data` — QR-код
- `La,x,y,x1,y1` — линия
- `Rx,y,x1,y1,lrw,ubw` — прямоугольник

**Управление:**
- `E` — завершение описания этикетки и запуск печати
- `~S,CHECK` — статус принтера (в будущем)

Подробное описание — в `EZPL_EN_J_20180226.pdf`.

## 10. Этапы разработки MVP

1. **Каркас проекта:** решение из нескольких проектов (Core, Excel, EZPL, Printing, UI), базовые модели, MVVM-инфраструктура
2. **Чтение Excel:** загрузка файла, отображение таблицы, выбор строк
3. **Модель шаблона и сериализация:** классы `LabelTemplate` / `LabelElement`, сохранение/загрузка JSON
4. **Редактор шаблона:** Canvas с drag&drop, панель свойств, панель элементов, привязка к сетке
5. **Рендерер превью:** отрисовка шаблона с подстановкой данных строки
6. **Генератор EZPL:** конвертация шаблона + данных строки в текст команд
7. **Модуль печати:** `RawPrinterHelper` (USB) и `TcpClient` (TCP:9100)
8. **UI-сборка сценария печати:** выбор принтера, тестовая бирка, пакетный запуск, прогресс
9. **Полировка:** валидации, автосохранение, локализация, установщик
